Agent Teams - a Slack where every channel is a team of agents

A CEO agent staffs a team from a goal, a PM agent hands out the work, and specialists report back.

Built at a hackathon with a classmate: a Slack-style app where each channel is a team of long-running AI agents, with a Next.js / React frontend and a Node.js backend. You give the CEO agent a goal; it proposes team options and launches one. The PM agent then assigns tasks, and specialist agents call real tools (web search, page fetch) and report back. The agents run on LangChain Deep Agents over LangGraph as persistent workers with task queues, inboxes and SSE streaming to the UI. Each agent's memory lives in a git-backed vault with history, diff and restore. LLM calls fall back to a second model when the first fails, and every call's cost, tokens, cache hits and latency is logged and traced in LangSmith.

Fish Recovery - real-time compliant voice agent

A LiveKit voice agent with Fish Audio TTS, LangGraph dialogue state, and FDCPA compliance gates.

Built a browser-based debt-collection voice agent that can run a live call flow: opening, identity verification, objection handling, payment-plan negotiation, recap, and close. The Python worker connects to LiveKit, routes each user turn through a LangGraph state machine, checks every generated response with a compliance layer, and streams speech through Fish Audio TTS. The React interface shows transcript logs, call controls, and live stage / emotion / verification chips from worker-published state instead of frontend heuristics.

Production RAG for a health optimization platform

5,000+ beta users. 8,000+ daily queries. 99.5% uptime.

Architected and scaled a retrieval-augmented generation system serving thousands of users on Google Cloud Run. The first version had a 2.3s response time and shaky retrieval quality. I instrumented the pipeline with AutoRAG, isolated the bottlenecks, then rebuilt retrieval around Weaviate with HNSW + hybrid (dense/sparse) search, overlapping chunking, and a cross-encoder reranker. Layered PathRAG on top to query a 50GB+ multi-domain health dataset as a graph. Deployed via Terraform-managed Docker on GCP with auto-scaling FastAPI workers.

BiteWise — AI meal planning that doesn't hallucinate

Top 30 finalist, TED AI hackathon (UN Sustainability Goals).

Android app for tracking dietary habits and getting personalized recipe recommendations. The technical challenge was hallucinations—LLMs love to invent ingredients and confident nutrition numbers. I structured the prompt chain with Chain-of-Thought via LangChain and tight grounding against tracked user data, cutting observed hallucinations by ~98%. Recipes get generated by Gemini, accompanying images by DALL·E 3, all stored in Firebase.
