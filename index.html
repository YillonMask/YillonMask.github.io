03

Hackathon, team of 2

Agent Teams · Multi-Agent Platform · 2026

Agent Teams - a Slack where every channel is a team of agents

A CEO agent staffs a team from a goal, a PM agent hands out the work, and specialists report back.

Built at a hackathon with a classmate: a Slack-style app where each channel is a team of long-running AI agents on LangChain Deep Agents over LangGraph. Agents run as persistent workers with task queues, inboxes and SSE streaming; each one's memory lives in a git-backed vault with history, diff and restore. LLM calls fall back to a second model on failure, and every call's cost, tokens and latency is traced in LangSmith.

Fish Recovery - real-time compliant voice agent

A LiveKit voice agent with Fish Audio TTS, LangGraph dialogue state, and FDCPA compliance gates.

A browser-based debt-collection voice agent that runs a full live call: identity verification, objections, payment-plan negotiation, recap and close.
