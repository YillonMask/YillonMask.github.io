1. **6 月全月主旋律已成型：*AI 信任经济* 从工具层崩塌到资本层重建**。
   - 工具层 **崩**：7 起供应链事件（Popa / 10k GitHub Trojan / JetBrains / Mastra / LiteLLM / Atomic Arch / Microsoft 73 repos）+ Fable 5 撤回 + 客观 "AI in branding -60%" 消费者调研。
   - 资本层 **重建**：OpenAI / Anthropic 9-10 月双 IPO + SPCX × Cursor $60B + Prometheus $12B + PhysicsX $300M + Midjourney Medical + Anthropic Q2 首次 $559M operating profit。
   - 制度层 **校准**：Fed AI task force（首次正式承认 AI 是货币政策变量）+ Munich Google AI Overview 判决 + HIPRA 法案 + EU DMA 临时令 + 美 export control 撤 Fable 5。
   *三层同时推进* 的概率结构：未来 6 个月 AI 行业进入 "**估值高但信任低 + 监管高但创新没停**" 的双叉路径。下半年最大产品机会：**transparent AI infrastructure**（agent observability + verifiable inference + provenance tracking + zero-trust MCP）。

2. **DeepSeek Vision + GLM-5.2 leading + Kimi K2.7-Code = 三周内中国开源 vision-code 全栈出齐**：5/27 后中国开源 AI 的 production-grade 节奏明显加速。配合 Fable 5 撤回 + Apple Foundation Models 进 Claude SDK = "开源不是 inferior，是 different tool"成为新共识。**对 AEC adjacent 创业者**：不再需要等 OpenAI / Anthropic API；可以直接基于 GLM-5.2 / Qwen 3 / DeepSeek Vision + 自有数据 fine-tune。**MCP 协议 enterprise managed auth** 同周出现是 *本地 + 开源 + 企业部署* 三件组合的最后一块拼图。

3. **Juneteenth 是个良好的 "Q2 mid-point reflection" 时间窗口**：过去 30 天关键事件 — Anthropic $965B Series H → Fable 5 GA → Amazon 触发撤回 → SPCX 史上最大 IPO → Apple Gemini + Watch 高管出走 → Prometheus $12B → Cursor 被 SPCX $60B 收 → FOMC 鹰派 + AI task force → Midjourney Medical。**Pattern**：① frontier lab 的产品-政策风险周期缩短到 *一周内* ② 大型公司的 AI 并购溢价（Cursor 在 9 个月内被估 $30B → $60B）③ industrial AI 形成 *generative + 收购实体* 与 *分析 + 决策层* 两条路径并行。**下半年要点**：Anthropic IPO S-1 法律风险章节、OpenAI IPO 商业模式披露、Prometheus 第一笔工业并购、Apple Watch S12 + Apple Loop。

4. **Hormuz 60 天 provisional 重开 + Lebanon 战事 = Iran 主题尚未完成定价**：6/15-18 油价从 $96 跌至 ~$80 是 *80% peace dividend*；剩 20% 在 6/22 起开盘后定价。如果 ① 6/19 推迟的瑞士签约能在 6/22-26 重新安排成功，油价可能再跌至 $75 ② Lebanon 升级或瑞士签约黄掉，油价可能反弹回 $90+。**AEC 类比影响**：油价稳定低位是 *建筑材料 + 物流成本* 直接减压。
