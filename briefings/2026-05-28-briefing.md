## 重点

- **Agentic Workflows 成为绝对主流**：无论是在云端模型（GPT-5.5-Cyber, Claude Mythos）还是本地开源生态（OpenClaw/Hermes），AI 已全面转向持久化、自主执行的 Agent 工作流。
- **资本向“硬”实力与基础设施集中**：AI 领域出现巨额 Mega-rounds（如 Anduril 50亿美元，Cognition 10亿美元），资本正加速逃离纯套壳应用，关注具有防御性基础设施与实体集成的企业。
- **可穿戴健康设备步入“临床级”竞争**：Oura Ring 5 携 Health Radar 与电子病历（Health Records）整合发布，与 WHOOP 的 AI My Memory 及 HealthEx 医疗数据接入形成全面竞争。
- **AEC 行业生成式设计落地日常工作流**：BIM 软件中的 AI 自动化（如预测性冲突检测、智能排布）正从实验性 Pilot 走向标准化日常执行层。

### 3. **📄 AI Research**
- **[Code as Agent Harness](https://www.alphaxiv.org/)**：来自 UIUC、Meta 和 Stanford 的研究。该论文提出将“代码”重新定位为 Agent 的“操作基质”（operational substrate），从而使 Agent 能够更好地执行长周期任务、建立环境模型并进行复杂推理。这是一个对 LLM Tooling 具有重要启发的架构思路。
- **[AutoResearchClaw](https://www.alphaxiv.org/)**：来自 UNC 的研究。提出了一个多智能体自动化研究 Pipeline，能够模仿人类的自我纠错和迭代科学探索，在 ARC-Bench 上取得了显著的性能提升。

## 想法

1. **“端侧”与“云端”的数据边界被打破**：LM Studio 与 MCP 的结合，使得本地模型能无缝且安全地处理私密数据。这是一个明确的信号——未来的生产力工具将是“云端大模型做重度推理，本地 Agent 做隐私数据整合和执行”。
2. **硬件即服务（HaaS）向“临床医疗级”跨越**：Oura 和 WHOOP 不约而同地在 5 月推出了电子病历（Health Records）整合与问诊服务。这意味着可穿戴设备已完成从“运动表现追踪”到“预防性医疗入口”的蜕变，健康数据的所有权和商业化路径正在重构。
3. **AEC 行业的 Agent 化机会**：目前 BIM 软件中的自动化仍偏向于“执行指令”。如果借鉴《Code as Agent Harness》的思路，将 BIM 的数据结构作为 Agent 的 Operational Substrate，可能会诞生下一代真正具备“设计自治”能力的工程协作平台。
