3. 📄 AI Research

  • Look Before You Leap: Autonomous Exploration for LLM Agents - 为什么重要：针对 LLM Agent 容易发生的“过早利用/执行错误”问题，提出了“先探索后行动”（Explore-then-Act）的范式。利用 ECC 评估体系引导 Agent 先与环境对齐，再具体执行动作，显著降低了错误率。
  • SkillOpt: Executive Strategy for Self-Evolving Agent Skills - 为什么重要：微软研究团队设计的文本空间技能优化器。它将 Agent 的技能视为可在外部自动演进和更新的“状态”，在确保持续自我演进的同时，实现了生产部署时零额外推理开销。

想法

  • 资本对头部 AI 模型（Anthropic）和全自动软件工程（Cognition）的顶级二八分化重注，意味着“通用型 API”的套壳创业大门已经关闭。未来的价值增量将大量存在于 AEC 垂直场景的 physical-agent 和 Oura Ring 等与物理世界传感器进行深度绑定的边缘大健康模型（Edge Health AI）上。
  • “无屏化/隐形计算”(Screenless/Invisible Computing) 正成为健康可穿戴的新浪潮。Fitbit Air 和 Oura Ring 5 说明设备在硬件上应该越来越“隐形”，但在 AI 层面却越加扮演“显性健康守护者”的角色。这对健康大模型的端侧轻量化与个性化提出了极高要求。
  • AEC 行业的未来不是生成更多天马行空的 3D 模型，而是将设计 (Revit/Forma) - 规划 (BIM) - 现场 (Dusty/HP Robotics) 通过自动化 Agent 链条形成完全闭环。谁能打通从设计图纸到施工机器人物理打样的端到端 Agent 链路，谁就能掌握下一个行业操作系统。
