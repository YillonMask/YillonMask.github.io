## 想法

1. **"AI security" 是这周最被低估的 wedge**：depthfirst $1k 跑出 21 个 0day + Anthropic Project Glasswing 同周释出 reference harness → 一旦 AI bug-finding 工具化成"按行扫码计价"，全球 sec audit 市场会被重塑。同时 rsync 那篇说明 *AI 写代码的 bug 引入率* 也是新的产品机会（持续 PR 质量 telemetry）。这是"AI 找洞 vs AI 制造洞"双向博弈，两边都有 SaaS 空间。
2. **指数被动资金缺席 + 利率重回 5% = mega-IPO 流动性结构改变**：SpaceX / OpenAI / Anthropic 上市后 12 个月没有 S&P 500 资金，加上利率回到 restrictive 区间，IPO 后股价波动会更剧烈。给二级市场的对冲策略和给一级市场的次级流通市场（Forge / EquityZen / Hiive）都是利好。
3. **Oura "Ring → AI Advisor → 临床 AI → 真人医生"四级漏斗** 是 2026 wearables 的范式样本。这条路可以照搬到：① CGM patch（Levels / January AI / Ultrahuman M1） ② sleep tech（Eight Sleep / Withings） ③ 心电类（Apple Watch / Withings ScanWatch）。AEC 类比：现场 sensor → AI 巡检 → 持照工程师签字。每个 vertical 都能复刻这个 "AI escalation funnel"。
4. **AEC 的 "agentic BIM" 现在是真正缺口**：AEC Magazine 连两期都在喊 BIM 平台要重构。如果有 startup 把 *现有 BIM 数据 + LLM agent + 规范库* 三件事用 MCP-style 协议串起来，能直接吃 Autodesk Forma / Hypar 没有覆盖的中段（plan checking / code compliance / 跨专业协调）。这是上次 briefing 提到的 BIM-as-context MCP 原型的更具体动机。
