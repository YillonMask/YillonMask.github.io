### 📄 3. AI Research

整体趋势：**RL pretraining 数据调度 + agent 真假代理性 + multi-user agent 治理 + agent communication 协议层** 成为 6/24-27 arXiv 新增主轴。

- [**Holistic Data Scheduler for LLM Pre-training via Multi-Objective Reinforcement Learning (2606.24133)**](https://arxiv.org/abs/2606.24133) — 用 RL 调度 pretraining 数据源混合比；**与 §3 Qualcomm Modular / GLM-5.2 MoE 数据策略形成上游对应**。
- [**Critique of Agent Model (2606.23991)**](https://arxiv.org/abs/2606.23991) — 五维度综述，**主张真正的 agency 必须内化、不能仅靠外部 scaffold** — 对当下 Patronus / Sail Research 等 sandbox 思路的方法论反驳。
- [**Harness-MU: Safe, Governed, Effective Harness for Multi-User LLM Agents (2606.21856)**](https://arxiv.org/abs/2606.21856) — multi-principal 场景下的 access permissions + conflict resolution；与 6/25 Runlayer $30M / Nebulock $25M 融资逻辑直连。
- [**AtomMem: Memory System for LLM Agents via Atomic Facts (2606.19847)**](https://arxiv.org/abs/2606.19847) — 与 §4 EHR + 个人 health graph 数据层、Oura Advisor AI 升级在工程哲学上同向。
- [**Reliability without Validity: Large-Scale Eval of LLM-as-a-Judge (2606.19544)**](https://arxiv.org/abs/2606.19544) — agent eval 的方法论拐点，**直接动摇 LLM-as-judge 范式**；Coval / Patronus 类公司需要把 eval 路径多元化。
- [**Technical Taxonomy of LLM Agent Communication Protocols (2606.19135)**](https://arxiv.org/abs/2606.19135) — 在 MCP 已经成为事实标准之后，第一篇综述层面的 ACP/A2A/MCP 比较，工业落地参考。
- [**AgentFairBench: Do LLM Agents Discriminate When They Act? (2606.16723)**](https://arxiv.org/abs/2606.16723) — hiring / lending / medical-triage 维度的 agent fairness 基准，**与 Trase $107M (regulated workflows) 商业逻辑直接相关**。
- [**EurekAgent: Agent Environment Engineering for Autonomous Scientific Discovery (2606.13662)**](https://arxiv.org/abs/2606.13662) — "bottleneck 已从 workflows 转向 environments"；**与 Sail Research $80M (stateful sandbox) 同月落地**，方法论与一级市场资金同向。
- [**Less Context, Better Agents (2606.10209)**](https://arxiv.org/abs/2606.10209) — long-horizon agent 的 context 工程效率；GLM-5.2 1M context 部署成本的反向思路。

## 想法

1. **"AI capex 资本市场资金回路"第一次被机构公开承认是一条风险** — JPMorgan 6/26 备忘把 OpenAI IPO 推迟 ↔ hyperscaler infra spending sustainability 写进同一句话，是 2026 年 Q2 最重要的市场叙事更新。**值得追踪**：(a) Anthropic 10 月 IPO 的认购 + 定价区间会成为 *frontier lab 私募估值* 的首次公开发现 — 如果跌破 $700B，将连带挤压 OpenAI 二级市场卖出价 (b) **SpaceX 给 Anthropic 的 35 个月 $44B 算力承诺**会成为"用 *已锁定 compute lifecycle* 替代 ARR"的新估值锚 — 这与 *Anthropic 是否"独立"于 hyperscaler* 的问题直接挂钩 (c) Meta $135B FY26 capex 上调说明 hyperscaler 侧并未受冲击 — 真正受影响的是 *frontier lab 之 capex / 营收循环依赖*。

2. **GPT-5.6 "customer-by-customer 白宫审批" + Sol cyber 96.7% 自主红队能力 = frontier 模型的合规边界被锁定在 *能力* 而非 *用途*** — 这与传统出口管制的"用途清单"逻辑相反，会改变整个企业 AI 采购流程。**值得思考**：(a) 如果"自主红队能力"被设为 *自动触发审批的能力阈值*，将让 OpenAI / Anthropic 在 *训练 vs 部署* 之间多出一层取舍 — 模型能力越强反而越难商业化 (b) **这条与 §5 efficiency narrative 形成对偶**：受合规阻挡的需求会快速迁移到 *自托管开源 1M context* — GLM-5.2 的 HK$1T 估值是这条迁移的二级市场预言 (c) **Northeastern / 学术机构在 *cleared list* 之外可能存在 *fast-track*** — 值得调研 OpenAI 是否对 R1 大学合作有简化通道。

3. **"去 NVIDIA / 去 CUDA"主轴在两周内出现四个独立信号（Jalapeño / Modular / Dragonfly + Meta/Azure 锚定 / Baseten $1.5B）—— 不再是"叙事"，而是 *资本 + 客户 + 编译器栈* 三件套同时落地** — NVIDIA Q3 财报（预计 8 月）会成为这条主线的第一次系统性定价。**值得思考**：(a) **Meta 把 Dragonfly C1000 CPU 列为 2028 部署** = 2 年 lead time 锁定，等同于 hyperscaler 公开为 Qualcomm 背书 — 这种"客户先锚定再发货"是过去 NVIDIA 独占的发布节奏 (b) **Baseten $1.5B 表示二级市场已经把 "跨硬件 inference 路由" 当成独立基础设施层**，与 OpenRouter $113M 同向 — agent stack 的最底层在分裂为 "Modular (编译) / Baseten + OpenRouter (路由)" 双层。

4. **DeepMind 一周失去 4 位核心 + Alphabet 周内 -5%+ = AI 实验室人才市场被 *公开做空*** — 这是过去 30 年硅谷顶级研究机构第一次出现这种规模的"无对价"流失。**值得思考**：(a) Jumper (AlphaFold / 诺奖) 加入 Anthropic 暗示 **Anthropic 押注 biology / drug discovery 作为差异化护城河** — 与 Oura × LillyDirect (§7) 在产业层不同但战略层同向（**AI × 健康 / 药物发现成为商业化最确定的下游**） (b) Shazeer 加入 OpenAI 与 Sol/Terra/Luna 的发布节奏紧密重叠 — 大概率参与 *next-gen architecture* 工作 (c) 这条与 §1 (OpenAI IPO 推迟 / Anthropic 10 月先上) 互相强化 — **资本与人才正在向"已确定 IPO 路径"集中**，第三极（Google / Meta AI / xAI / 国家级 frontier）的"叙事 mind share"在二级市场被一次性折现 -5%+。

5. **wearable "regulatory arbitrage" 形成 — Whoop 走 wellness 快通道、Apple / Samsung 走 SaMD 慢通道，但 Samsung × Alcedis 的 *clinical endpoint 通道* 又是另一条** — 三种合规路径并存意味着 H2 wearable 厂商**真正的竞争位是 "选哪条合规通道"，而不是"做什么功能"**。**值得思考**：Apple / Samsung 是否会发起对 FDA 的对等监管诉求？如果是，下一波 wearable 临床化窗口可能在 *2027 年 Q1 FDA 新一轮指引* 出现。
