### 3. 📄 AI Research（[alphaXiv trending](https://www.alphaxiv.org/)）

- [**Code as Agent Harness (5/18)**](https://arxiv.org/abs/2605.18000) — UIUC + Meta + Stanford，把 code 从"LLM 输出"重新定位为"agent 运行的操作底层"。18 个 LLM backbone × 7 个 deterministic agent 环境，**平均相对性能提升 88.5%**。"代码即 runtime"成为 agent 工程化的新默认。
- [**Cattle Trade: Multi-Agent Benchmark (5/14)**](https://arxiv.org/abs/2605.14537) — 拍卖 + 隐藏报价 + 议价 + 虚张 + 对手建模 + 资源分配，单场 50-60 turn 的长程博弈基准。**专门压测 imperfect information 下的策略推理**——Claude / GPT / Gemini 谁能在博弈层面稳定不掉链子是接下来 6 个月的新分水岭。
- [**The Alpha Illusion (5/16)**](https://arxiv.org/abs/2605.16895) — 把 FinCon / FinMem / TradingAgents / FinAgent / QuantAgent / FLAG-Trader 一起测，结论是 LLM trading agent 的 backtest alpha 不应被视为可部署证据。**AI 金融 agent 创业 narrative 的精确反击**——上周已经传播一次，本周还在榜。
- [**Constraint Drift in LLM-Based Multi-Agent Systems (5/11)**](https://arxiv.org/abs/2605.10481) — multi-agent safety constraint 必须持续 maintain 而不是断言一次就完，提出 Constraint State Governance 范式。
- [**Insider Attacks in Multi-Agent LLM Consensus (5/08)**](https://arxiv.org/abs/2605.08268) — 多 agent 共识系统里的内部攻击模型——agent 安全研究开始从 prompt injection 上升到分布式系统层。

## 想法

1. **OpenRouter 数字最值得做笔记**：周 token 5T → 25T（6 个月 5x），且企业 67% 已经月耗超 10 亿 token。这意味着**多模型混用 + 路由不是边缘选择，而是默认架构**——任何"只接一家 LLM"的产品形态都要重新想。如果做 daily briefing / agent 工具，OpenRouter 这层完全可以当 backbone。
2. **Anthropic 利润 caveat 是关键信号**：non-GAAP + 单一算力折扣 = "盈利数字是商务谈出来的，不是物理结构变好的"。配合 Karpathy 加入 + SpaceX 算力包，Anthropic 在用"短期估值溢价 + 算力锁仓"换取**通向 IPO 之前的 narrative**。看 Q3 是否真能站稳 GAAP 盈利。
3. **AEC × Agent 第一次有了可被工程师 demo 的场景**：Augmenta MEP 自动 25 英里布线意味着"AI 给数据中心画施工图"已经技术可行——下一步是 BIM 数据接口（MCP for BIM）+ 责任界面（谁签字）。这是一个**结构性的 niche entry point**：BIM agent 的 RAG / MCP 等价物今天还没有公认实现。
4. **Oura + Dexcom CGM 整合方向 = 真正的 health stack**：代谢 + 压力 + 睡眠 + 体温 + HRV 在 ring 一只手指上集成是 5 年级别的产品方向。如果做 wearable × AI 项目，**第三方算法层（不绑硬件，跨 ring/watch/CGM 做模型）**反而是被低估的一层。
5. **量子 IPO 同步开闸（Quantinuum $12.7B + IBM 分拆）值得标记**：AI 高位 + 量子商业化窗口同时打开是历史第一次，对硬件供应链 / 资本配置 / 国家 strategic stack 的影响在 2-3 年内会显化。
