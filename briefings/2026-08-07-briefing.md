### 📄 3. AI Research

- **Argus：让 agent 能安全地自主修改任务目标的通用运行时**：由 Manager、Planner、Engineer、Reviewer 四个角色在持久化项目状态上协同执行任务，新记忆、技能、路由决策只有经过角色专属审核、并尽可能通过任务原生验证后才会被采纳；在 GPT-5.5 的七个基准测试场上，SWE-Bench Pro 达到约 78%（直接用 Copilot 仅 59%），代价是多用 1.41 倍 token。对做长程 agent（深度研究、多天任务）的团队，这是目前少见的"允许 agent 自主改目标但不失控"的架构参考，与本期"重点 4"的 agent 信任议题直接呼应。 [来源](https://www.alphaxiv.org/abs/2608.05144)
- **HarnessOpt-Bench：第一个系统评测"LLM 能不能自己优化自己的执行框架"的基准**：让一个"优化器 LLM + 编码 harness"拿到目标 agent 的初始 harness、评分反馈和固定预算，去修改 harness 并提交最终版本，在留出测试集上打分；覆盖 5 个前沿模型、4 个下游任务、111 次评测运行，发现"优化器模型本身的差异，比它们所用的编码 harness 的差异更大"、且"原生 harness 不总是比通用 harness 更优"。这是"harness engineering"叙事第一次有了标准化的可比较基准，值得所有在做 agent 自我改进的团队关注。 [来源](https://arxiv.org/abs/2608.06301)

## 想法

1. **"agent 自主性该由谁把关"这个问题，今天同时出现在学术论文、大厂头条和独立开发者产品里**：HN 的审批疲劳研究、alphaXiv 的 HarnessOpt-Bench/Argus、Product Hunt 榜单里的 Soloop——三条完全独立的信息线在同一天指向同一个结论：human-in-the-loop 本身并不可靠，行业正从"让人审批"转向"让系统结构性地限制 agent 能做什么"。值得画一张"agent 信任层"全景图，横向比较学术界、平台方、独立开发者三条路径的方案差异。
2. **顶级研究人才带着老东家的钱出走创业，可能正在成为大厂留不住 AI 人才的新解法**：Jeff Dean 团队创立 Discovery Loop 时 Alphabet 本身也是出资方之一，这种"离职但不撕破脸、继续绑定利益"的模式，如果被验证有效，未来可能会在 OpenAI、Anthropic、Meta 等公司看到更多类似案例——相比传统的"人才流失是零和博弈"叙事，这是一种更接近"内部孵化外部化"的新关系。
3. **芯片层的"去英伟达化"正在从概念验证走向真金白银的并购**：AMD 收购 Taalas、英伟达此前对 Groq 的巨额授权、DeepSeek 在非英伟达硬件上持续优化部署——三条线共同指向同一个方向：agent 推理时代的芯片竞争不再是单纯堆算力，而是"给特定模型定制硬件"这条路径正在被主流玩家验证为可行商业模式。
4. **AEC 和可穿戴两个垂直行业，都在上演"硬件老牌厂商反向抄作业"的剧本**：Garmin 推出无订阅费的 Cirqa 正面对标 WHOOP，Bentley/Trimble 把生成式 AI Copilot 嵌入自家旧 BIM 产品线而非任由 Higharc、Hypar 等初创公司抢跑——传统硬件/软件巨头没有被颠覆，而是选择用"更低定价+更成熟渠道"把新玩法据为己有，初创公司（TerraFirma 除外）在这两个垂直领域的融资规模明显小于纯软件 AI 赛道。
