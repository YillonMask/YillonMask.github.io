想法

  1. "去 CUDA 周"叙事正式坐实 — Jalapeño + Modular 在同一日落地，加上上周 OpenRouter $113M / vLLM Semantic Router，组合起来意味着 "model layer + compiler layer + routing layer" 三件套在 2 个月内出现了三个独立信号。值得追踪：(a) Jalapeño 的实际芯片规格（TSMC 制程 / HBM 配置）在年底发布会披露后，与 NVIDIA Blackwell B300 / TPU v6 横向对比 (b) Modular MAX 在 Qualcomm 收购后的开源策略变化 — 是否保持"hardware-agnostic"是 CUDA 替代叙事的关键试金石。
  1. "AI 成本通胀外溢"首次成型 — Apple 6/25 Mac 涨价 + Microsoft Xbox 涨价 + PCE 4.1%，三个独立信号在同一日叠加。值得思考：消费电子 BOM 涨价是"短期 cycle"还是"结构性 phase"？ 如果是后者，下一波传导可能是 ① 服务器 OEM (Dell / HPE / SMCI) 利润率压缩 ② 大型 SaaS 厂商把 inference 涨价转嫁给企业客户（OpenAI ChatGPT Enterprise 已悄悄重新议价） ③ 与 AI 不直接相关的硬件（家电 / 汽车信息娱乐系统）开始 memory cost 上调。
  1. AEC 的"owner-side AI agent"正在成为 contech 下半场的真正主战场 — Procore (Datagrid 收购 + 6/17 Innovation Summit) 与 Autodesk (MaintainX 收购) 都在把战线从 design / construction 阶段拉到 owner / operate 阶段。值得跟踪：(a) Palantir 切入 AEC 后，是会以"Foundry for AEC"产品形态出现，还是先做 partnership 嵌入 Autodesk Construction Cloud？(b) Bedrock Robotics 与 Procore Marketplace 是否会在 Q3-Q4 出现 OEM 级数据互通 — 若是，"机器人作为 BIM 数据源"将成为新范式。
  1. wearable 的临床化拐点是"数据 unification > AI 顾问" — Oura Ring 5 EHR import 6/30 上线 + Whoop EHR sync 是这一周最被低估的结构性信号。真正稀缺的不是"更准的 sleep score"或"更聪明的 AI advisor"，而是把 lab work + EHR + 连续生物数据合在同一个 personal data layer 里。这与 Anthropic-Alibaba 事件（API 行为级合规）在底层逻辑上一致 — 数据归属与统一访问层 = 下一个 5 年的护城河层。
