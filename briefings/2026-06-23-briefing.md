## 想法

1. **Google AI talent 失血 = "frontier lab 中 incumbent vs disruptor" 力学最新数据点**：Shazeer 是 Gemini AI 共同负责人，VP Engineering — 这一级别离职在过去 3 年极罕见。Jumper（2024 化学诺奖）去 Anthropic 是 *科研声誉 + 商业前景双重押宝*。**Pattern**：Google 的 *研究文化 vs 产品执行* 在 AI 时代失衡——OpenAI / Anthropic 提供更明确的"产品+股权"组合。AEC 类比：Autodesk / Bentley 的 AI 团队也会面临 *被 PhysicsX / Prometheus 挖人* 的同结构压力。机会：① 二级市场 short GOOGL / long OpenAI 二级 ② 一级市场 vertical FM 公司的 *AI talent + 行业 know-how* 双 moat ③ AI talent intelligence 服务（追踪谁去哪、谁带谁）。
2. **SPCX 4 日 -31% 是 *史上最大 IPO 的 reality check*；触发 OpenAI / Anthropic IPO 估值修正**：① $60B Cursor 稀释暴露 *all-stock 收购的 buyback 反向效应* ② 期权交易引入 shorts → 价格 discovery 加速 ③ 104.7× P/S + 负利润是 *任何 metrics 都不支持* 的估值。对 OpenAI 9 月 IPO $730B、Anthropic 10 月 IPO $60B+ 募的影响：① 银行会用 SPCX -31% 作为 *估值下行锚* 与公司谈判 ② pre-IPO 二级市场（Forge / EquityZen / Hiive）的 *OpenAI / Anthropic 报价* 可能整体下移 10-20% ③ "AI mega-IPO supercycle" 这一叙事面临首次正式 stress test。
3. **OpenAI Daybreak + GPT-5.5-Cyber 是 frontier lab "vertical 化"第一次具体落地**：之前 Anthropic 是 Glasswing + Mythos 5（被政府撤回）+ Claude API 通用。OpenAI 用 Daybreak *直接做产品* — 包括 fine-tuned model + Codex 插件 + 合作伙伴计划 + "Patch the Planet" 公益项目。**这是 frontier lab 走出 model-as-API 的标志**：① 给 cybersecurity vertical 树立 model + product 标杆 ② Patch the Planet 与 cURL / Go / Python 等关键开源项目深度绑定，建立 *defensive distribution channel* ③ 直接抢 Anthropic 在 cybersecurity 的市场份额（Fable 5 撤回后真空）。**AEC 类比信号**：未来 1-2 个季度 OpenAI 可能推 *Construction / AEC fine-tuned + Patch the Planet 同结构* 产品。
4. **本周 6 月最后一周完整收尾："Russell 2000 + Apertus + Local GLM + Codex bug + SPCX 崩 + Google 失血"** = AI 故事三个 cluster 同时反转：
   - **大盘股反转**：Mag7 单股压力 vs Russell 创新高（rotation）
   - **frontier 反转**：Codex bug / DifyTap / GOOGL talent 走 vs 开源 GLM / Apertus / 主权 AI 加速
   - **IPO 反转**：SPCX -31% reality check vs OpenAI / Anthropic 估值锚定下行
   *6 月这一波结构性事件* 把 AI narrative 从 *"无止境上行 + frontier 集中"* 拨向 *"capex peak + 开源接管 + 大盘股 rotation"*。下半年 thesis 已经清晰。
