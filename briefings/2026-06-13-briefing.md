## 想法

1. **Fable 5 事件正在催熟"AI 主权化"叙事**：HN 24 小时内 ① Fable 5 撤回帖 1,838 → 2,950（+60%） ② Open Source AI Must Win 678 → 1,406（+107%） ③ Kimi K2.7-Code 开源新模型 440 ④ "Local coding agent on macOS" 教程 455。**社区共识在 24 小时内完成切换**：从"看 Anthropic 怎么响应" → "我必须有 fallback 路径"。机会窗口（短期 2-4 周）：① model-agnostic 路由产品（Cursor / Cline / Aider 这一层）会被反向利好 ② edge-AI 部署工具 ③ "open-weights guarantee" 这种 SLA 服务。从政策面看，**OpenAI 等若没被同样 directive 影响，将获得短期巨大份额转移**——这点 Anthropic 在声明里已经公开喊话不公平。
2. **Musk = 第一个 trillionaire + SPCX $2.11T 是"个体资本权力"新水印**：过去一年 ① Musk 用 SpaceX 收购 xAI ② Google 月付 SpaceX $920M ③ 现在 SPCX 让 Musk 个人净值 $1.1T。单个个人可调度 $1T 流动性 + 1+ 万亿市值的实体公司 + AI / 卫星 / 火箭三栈 = 治理结构史无前例。**对比 Bezos $12B Prometheus + Berkshire 式工业并购** = "trillionaire 时代的资本配置者用 AI + 实体合并方式重塑产业"。AEC / wearables 类垂直 vertical 都可能成为标的（Prometheus 已经明示）。
3. **Wearable 监管 + 数据治理三重压力本周完成**：① HIPRA 法案推进 ② Whoop / Oura BIPA 集体诉讼 ③ Ultrahuman 68 天迟报。三件事共同结论：**当前 wearable 的 estimated CAC / LTV 模型基于 freemium + 第三方 SDK 变现 + 慢响应文化，将被强制重写**。机会：① "Privacy-first wearable" positioning（自有 SDK、零第三方 tracker、24h 通知 SLA） ② 第三方 *wearable security audit* 服务 ③ HIPAA-grade 硬件（如 Sibel Health）会被重新估值。
4. **AEC 的 *discipline-specific AI* 路径被 NEXUS + HVAKR + PhysicsX 同时验证**：上周笔记 "BIM-as-context MCP 原型" 现在有了三个独立同步的产业信号 — 不要做大而全的 BIM-AI 平台，做 HVAC / 结构 / 给排水 / 电气 各自的小 vertical 模型，再用 *MCP-style 协议* 串到 BIM。Autodesk Forma 在做大而全的路径会比这种 *分而治之* 路径慢。**周末值得快速做的 prototype**：选一个 sub-discipline（比如 HVAC duct sizing），用 IFC 数据 + Claude Code（外籍员工现在用不了 Fable 5）+ MCP 协议串一个 demo。
