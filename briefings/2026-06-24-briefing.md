## 想法

1. **6/23 抛售 + 6/24 Micron beat = AI 半导体"叙事估值 → 业绩估值"切换点**：KOSPI 熔断 + Nvidia / Micron / TSMC 一同 -3% 到 -11%，盘后 Micron 报出营收 4.5× YoY 又拉回 +9%。**market 在重置"AI 板块的估值标尺"** — 从 P/S 比看 narrative 到 P/E + 终端订单看 supply / demand 真实。这次切换之后，**没有真实订单的 AI infra/SaaS 第二梯队会在下半年加速去泡沫**；有 hyperscaler 锁单的硬件（Micron / Nvidia / CoreWeave / Nebius）反而是 *被低估* 的 lower-vol 配置。**机会**：① 看 6/26 PCE + Micron 盘后细节后挑选 dip-buy 时点 ② OpenAI/Anthropic IPO 估值锚定从硬件业绩反推 ③ SPCX 第二周流动性测试 + lockup 后的 secondary 报价跟踪。
2. **小模型 + 主权 AI 第二季：VibeThinker-3B + Baidu Unlimited-OCR + FUTO Swipe + Apertus 4B = 一周内 4 个真正可用的"开源小模型 + on-device + 可验证"产品**。这是 6 月最大的结构性叙事 — 上周还停留在"开源模型能不能跑通"，本周开始变成"开源 + 小 + verifiable + on-device 已经在真实任务上压过封闭旗舰"。**预测**：① Anthropic 7/8 ID 验证后，consumer 会用脚投票，**Apertus / Qwen / VibeThinker / DeepSeek 的本地部署需求会有明显抬升** ② OCR / 翻译 / agent harness / 键盘输入这种"高频低成本"任务会率先被开源小模型吃掉 ③ Cloud LLM 厂家需要在 7-9 月用"长上下文 + 多模态 + agent"差异化护城河，否则 IPO 估值锚要重估。
3. **CISA 把 AI gateway 列入 KEV → vLLM Semantic Router 架构论文成形 = AI infra "plumbing 层"正式被工程化定义**：6/22 LiteLLM 补丁死线后立刻有 [Workload-Router-Pool 架构论文（arXiv 2603.21354）](https://arxiv.org/pdf/2603.21354) 提出 vLLM 语义路由。**整个 AI inference pipeline 正在从 SDK 调用上升为"系统软件"**。**机会**：① 国产 / 欧洲合规版 multi-LLM gateway（Portkey / Helicone / 中国 RouterAI 等）② AI gateway 的 SOC/SIEM 集成 ③ 在 PR 与监管层把 AI gateway 当 K8s 一样标准化的开源项目。
4. **Whoop FDA 解局 + Clair $11M = 可穿戴进入第二波 IPO + 第三轨硬件**：Whoop 解决 BP 隐患后 IPO 通道清空，**Oura + Whoop 双 IPO 在 Q3-Q4 高概率落地**；与此同时 Clair 把激素 lab 直接做到手腕，**ring/band 不再覆盖所有用户场景**。**对个人项目**：如果做 wearable × AI，**不要再赌"通用 ring/band"硬件**，而是切分人群（女性激素 / 老年代谢 / 慢病管理）+ 在数据 / 算法 / 临床路径形成 vertical AI 应用，反而是 *underprovisioned* 的市场。
5. **VARM 与 BuiltWorlds 40 名单同周 = AEC AI 进入"市场分层"阶段**：欧洲银行 + 气候基金已经在 building energy AI 下注（VARM），美国行业媒体（BuiltWorlds）已经能列 40 个 AEC AI 玩家 — **AEC AI 不再是 niche frontier**。下一步是 ① 谁能做 **MCP for BIM / IFC-native LLM** 这条"AEC agent 协议层"② 谁能整合 lifecycle（Autodesk 已经买 MaintainX 占 Operate）③ 谁能从中小 AEC 事务所 SaaS 起飞做 enterprise（Hypar 2.0 押注 schema-less LLM）。**对 AEC adjacent 项目**：不要去抢 design / BIM core，去做跨阶段的 agent orchestration + data quality + 责任 / 合规层。
