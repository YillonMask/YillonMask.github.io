### 📄 3. AI Research

- **LongHorizon-Harness: 把长程 agent 执行重构为"任务状态管理"问题**：不再让任务状态、执行过程和完成度判断都堆在不断增长的 context 里，而是维护一份独立于执行之外的显式任务状态记录，只允许被环境独立验证过的事实写入，再用 Manage–Execute–Audit 循环逐步派生下一步子任务；在 WeaveBench 上把 PassRate 从 51.8% 拉到 80.7%，接近此前 Claude Opus 4.7 官方最好成绩 41.2% 的两倍。对做长时间运行 agent（深度研究、多步骤 computer-use）的团队，这是一个"状态管理优先于换更强模型"的架构参考，与本期 HN 信号中 Lilian Weng 的 harness engineering 论述相互印证。 [来源](https://arxiv.org/abs/2608.01964)
- **SKT: 用可验证的合成数据批量训练 LLM 使用外部 Agent Skills**：不靠把技能文档硬塞进 prompt，而是构造经过验证的合成训练数据教模型调用外部 Skills，在多个 benchmark 与不同 harness 上都带来一致提升，且效果高度取决于合成数据的质量与验证严格程度。对正在做 tool-use / skill 微调的团队，这是一套直接可复用的数据构建方法论。 [来源](https://arxiv.org/abs/2608.02287)

## 想法

1. **"给模型包裹更好执行系统"这件事，正在从 AI 研究本身延伸到垂直行业软件层**：Harness Engineering（Lilian Weng + LongHorizon-Harness）论述的是通用 agent 执行框架，而 AEC 侧 Autodesk 把 agentic AI + 开放 MCP 内嵌进 Revit 核心产品、Sledge 做"投标到收款"全流程 AI 运营——本质上是同一套"scaffolding 优先于换模型"逻辑在不同层级的重演，值得做一张跨行业的"harness 渗透层次图"。
2. **代码供应链、同行评审、安全公告三条不同"信息供应链"同时爆发信任危机**：Shai-Hulud npm 蠕虫（代码供应链）、NeurIPS/ICML 隐藏 prompt 陷阱（评审供应链）、SQLite AI slop 疑云（安全公告供应链）——三者看似无关，但都是"本该高可信度的把关机制被自动化力量（恶意脚本 / AI 代写 / AI 生成失真内容）系统性突破"，值得横向对比这三种失效模式是否同构。
3. **资本正在向"AI 应用层"和"AI 治理/基建层"两端同时集中，中间的垂直行业层融资规模明显更小**：Simile（应用层，$2B 估值）与 Onyx Security、groundcover（治理/可观测性基建层）单笔融资额远超 AEC（GreenVibe $12M）、可穿戴（Clair Health $11.6M）等垂直赛道——资本的"哑铃型"分布，可能反映投资人认为中间层的差异化壁垒更薄。
4. **Apple v. OpenAI 的商业机密诉讼，与 Oura v. Samsung 的专利战，是同一现象在不同硬件赛道的重演**：两起诉讼都发生在"消费级可穿戴/设备硬件"正成为 AI 公司必争之地的背景下——当软件层差异化收窄，硬件专利与商业机密正在变成新的竞争边界和法律战场，预计未来还会看到更多此类诉讼。
