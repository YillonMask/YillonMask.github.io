想法

  1. "垂直 workbench + 底座 model 同日发" 是 lab 的新 GTM 范式。Anthropic 用 Sonnet 5 + Claude Science 同日示范：底座模型 downshift 价格锁 API 商品化，垂直 workbench 抓 高价值 + 数据 gravity + workflow lock-in 的科研 / 法律 / 医疗 / 金融四大垂直。观察：OpenAI 下一波是否直接 Ship ChatGPT for Medicine / for Law？如果 H2 出现 3 家以上 lab 同步发 vertical workbench，则 水平层 API 定价 会在 2027 Q1 前进入 持续下探 + 亏损 阶段 —— 这是给 Together AI / Fireworks / DeepInfra 之类 model-serving 中间商 20 个月 window。
  1. AEC AI 双极融资：住宅 (Higharc) + 数据中心 (Omen AI + OpenSpace) 同日 —— 提示 AI 基础设施 capex 已经足以反哺一整条 AEC AI 供应链。观察点：**如果 hyperscaler 开始把 数据中心设计 AI + MEP AI + 施工监控 AI 打包采购**（例如 Meta / Amazon 内部 spin off），会催生 proprietary AEC AI 甲方标准 —— 这对 乙方 SaaS 型 AEC AI（OpenSpace / Buildots） 是长期威胁，对 toolchain provider（Trimble / Bentley / Autodesk） 是护城河。深挖方向：Meta Reality Labs / AWS re:Invent 2026 (12月) 是否公开数据中心 AEC 内部 stack。
  1. wearable → 保险闭环 的临界点已经很近。Oura × Essence Health 是 Medicare Advantage 里的 sample，如果 Q3 出现 first commercial insurer 报销 ring / band 的公告（尤其是 Aetna / UnitedHealth Optum），wearable 商业模式在 H2 会从 硬件 + 订阅 变为 硬件 + 订阅 + 保险 rebate。深挖方向：关注 Optum + Whoop / Oura + FDA 三方 pathway 的公开信号（最可能通过 health economics abstract 在 AHA / ACC 秋季学术会露头）。
  1. **Claude Code steganography 会是 H2 AI supply chain trust 主线的引爆点。今天已经从 6/30 的 348 pts 升到 7/1 best 的 2,331 pts** —— 数量级放大。若 Anthropic 官方回应 技术上合理但业务上不透明，则会同时触发：(a) 企业客户合规审计 (b) 竞争对手 dark-pattern 反攻 (c) open-weights 阵营营销 wedge。深挖：whether GLM / Qwen / Leanstral 会不会主打 "no watermark / auditable" 差异化 —— 观察 7 月前两周 open-weights 阵营的官宣措辞。
