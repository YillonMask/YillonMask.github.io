### 📄 3. AI Research

**6/26-29 arxiv 主线** = **MoE 高效部署 + 优化器谱性能 + 线性 Transformer 学习 attention 核 + Curriculum & 分层 attention 调度**：

- [**FlexMoE: One-for-All Nested Intra-Expert Pruning for MoE LLMs (2606.27866)**](https://arxiv.org/abs/2606.27866) — **一次训练，多预算部署**；与 §3 Lindy 切换 DeepSeek + GLM-5.2 大 MoE 自托管成本曲线高度相关。
- [**Aurora: A Leverage-Aware Spectral Optimizer (2606.27715)**](https://arxiv.org/abs/2606.27715) — 解决 *tall matrices 的 row-norm 非均匀* 同时保留 Muon 几何性质；继续推动 SGD/Muon → spectral optimizer 演进。
- [**Flexformer: Flexible Linear Transformer with Learnable Attention Kernel (2606.27748)**](https://arxiv.org/abs/2606.27748) — *数据驱动 RFF attention kernel*；亚二次 cost 下与标准 Transformer 性能可比 — 长上下文 + 边缘部署的方法学储备。
- [**Learning to Reason with Curriculum II: Compositional Generalization (2606.27721)**](https://arxiv.org/abs/2606.27721) — autocurriculum 把序贯计算任务的监督复杂度降到 *亚多项式*；与 reasoning post-training 的 H2 主线 (RL with verifiable rewards) 互补。
- [**Prism Transformer: Progressive Head Schedules for Hierarchical Attention (2606.27449)**](https://arxiv.org/abs/2606.27449) — *单调递增的 head 数 → 局部到全局* 自然层次，**零参数 / 零 FLOP 开销** — 实战 retrofit 友好。
- [**COOPA: Modular LLM Agent Architecture for Operations Research (2606.27611)**](https://arxiv.org/abs/2606.27611) — agent + multi-solver routing + 迭代置信度，**interpretable OR**；与 Trase / Taktile 受监管行业 agent 商业逻辑同步。
- [**CBD: API-Only LLM Black-Box Unlearning (2606.27683)**](https://arxiv.org/abs/2606.27683) — API-only 通过 *auxiliary models + Fisher matrix* 做 unlearning — 直接对应 §1 Mythos / Sol USG-gated 体系下 *不可重训的合规 unlearning 路径*。
- [**RS-Diffuser: Risk-Sensitive Diffusion Planning with Distributional Value Guidance (2606.27767)**](https://arxiv.org/abs/2606.27767) — offline RL + diffusion trajectory + quantile distributional critic。
