## 想法

1. **SPCX × Cursor 是 AI coding 第一次 "frontier 厂 + IDE" 全栈整合**：之前 Cursor 通过 model-agnostic 路由（Claude / GPT / Gemini）拿到 $2.6B ARR。一旦被 SpaceX 收购，Cursor 默认会优先 xAI 模型 → Anthropic / OpenAI 失去最大的第三方 distribution。**短期影响**：① Cursor 的非 xAI 用户会评估 migration ② Cline / Continue / Aider / Codeium 等 *仍然中立* 的 IDE 会接住 distribution ③ Anthropic / OpenAI 自己的 IDE（Claude Code / Codex）必须加速。**长期更深远**：AI 编码 = *底层模型 + 编辑器 + agent 编排 + 部署* 全栈竞赛，这次收购把 *frontier lab + IDE* 这层正式合并。对应：未来 12 个月 OpenAI 收购 Windsurf / Anthropic 收购某编辑器 概率大幅上升。
2. **"本地模型够好了"在 24 小时内完成共识**：HN 1,229+519+785+353+352 五个高分帖同周聚焦本地 coding；评论里推荐已经具体到 Qwen 3 Coder + DeepSeek V3.5 + Kimi K2.7 + Devstral + GLM 5.2 组合。叠加 Apple Foundation Models 进 Claude SDK docs，**多模型路由层（router-of-routers）变成 distribution 必备**。机会：① 本地 + 云混合 *cost-routing*（PointFive / CAST AI / Runware 的下一形态） ② "open-weights SLA" 服务（按 model availability 计费） ③ 端侧 Mac Studio / Strix Halo 集群作为 *AI personal infra* —— HN "My Homelab AI Dev Platform" 已经在跑。
3. **LiteLLM CVSS 9.9 揭示 *AI gateway* 是新的供应链 chokepoint**：4 个 CVE 串联，最终通过 MCP subprocess 劫持 Claude Code 响应。这是 *第一次正式案例显示 MCP 协议本身可被武器化*。对照 6/8 Microsoft 73 repos 入侵、6/11-13 Atomic Arch 400+ AUR 包、Ultrahuman 68 天迟报 = **AI 工具链 + 数据供应链 + wearable 数据 三层信任都在 6 月集中 collapse**。短期机会：① *AI gateway hardened SKU*（hosted + audited LiteLLM 平替） ② MCP 协议 *signed-callback* 标准 ③ *agent prompt-flow* 的 cryptographic 审计层。
4. **Iran 框架协议 + SPCX 二日续涨 + Cursor 收购同日 = 风险资产 "三重利好" 但 breadth 极窄**：S&P / NASDAQ 创新高靠的是 SPCX + Mag7 + Iran 缓和。breadth indicator 仍然窄。今晚 / 明天 FOMC 任何鹰派意外（dot plot 上修 / Warsh 鹰派措辞）都会触发 V 型回撤。**策略**：① short Mag7 vol 现在的 IV pricing 偏低 ② Iran 主题股（航空 / 旅游 / 中东 ETF）适合 momentum 切入 ③ AI coding adjacent（小型 IDE / 编辑器 / MCP 工具公司）短期受 SPCX-Cursor 利好但中期是 *被收购 or 被边缘化* 二选一。
