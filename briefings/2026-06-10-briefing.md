## 想法

1. **Claude Fable 5 的"动态 fallback"是产品安全设计的分水岭事件**：Anthropic 在用户不知情下把高风险 query 切到 Opus 4.8。HN 999 分的批评帖标题就是"如果 Fable 停止帮你，你永远不会知道"。从产品角度这是 *safety theater*；从企业角度这是 *risk-managed throughput*。这套机制可能会被所有 frontier lab 学走（OpenAI 已经在做更轻量的版本），但 *对用户透明度* 这条会变成下半年的核心争论。机会：第三方 *agent observability* 工具（追踪每次 query 实际由哪个 sub-model 处理），可能是下一个被 well-funded 的 niche。
2. **德国 Munich 判决重塑 AI answer engine 经济学**：传统搜索引擎能躲在 Section 230 / DSA 框架后，AI Overview 不能。如果判决站稳，Google / Bing AI Overviews / Perplexity / SearchGPT 都需要重做内容审核 + 责任保险。结合 Fable 5 的 dynamic-fallback：*AI answer engines* 会被迫从"自信答案"转向"明示不确定性 + 引用源"。市场上 Perplexity 类公司是受冲击最大的，因为 *answer-first* 是它们的 wedge。机会：合规优先的 "verifiable-answer" 引擎（每条声明都有可点击的原文锚点 + 法律免责梯度）。
3. **Microsoft 73-repo 事件 + Anthropic Glasswing + depthfirst FFmpeg = AI 工具链供应链战开打**：5/28 Anthropic Glasswing 释出 → 5/29 depthfirst $1k 跑 21 个 FFmpeg 0day → 6/8 Microsoft 73 repos 被注入凭证盗 → 6/9 Veeam CVSS 9.4。这一周 AI sec 已经走过 *研究-工具化-真实事件* 全周期。下一阶段：保险公司开始针对 *AI-assisted dev pipeline* 推产品（已经有保险公司在内测 "AI coding agent insurance"）。
4. **Apple 同时输出 Gemini 集成 + Loop 概念发酵 + Watch S11 测评第一 = Apple Health 战略调整中**：Loop 是概念稿但叙事价值极高（screenless = 直击 Whoop/Fitbit Air）。Watch S11 在测评上反超 Oura（睡眠分期 + 免订阅）但仍卖订阅向（Apple Fitness+）。如果 Apple 真出 Loop @ $99-149，Whoop 的 $30/月订阅模型直接受冲击；Oura 在 ring form factor 上还有 1-2 年缓冲。AEC 类比：Autodesk 如果同时出 *免费 BIM viewer + AI agent layer*，Hypar / Higharc 也会面临类似的 *巨头降维* 风险。
