### 📄 3. AI Research

整体趋势：**MoE 量化效率 + agent budget-awareness + KV cache 长上下文优化** 三条主线在 6/23-26 各自出现至少一篇代表性论文。

- [**BitsMoE: Spectral Energy-Guided Bit Allocation for MoE LLM Quantization**](https://arxiv.org/abs/2606.00079) — 与 GLM-5.2 (744B MoE) 部署经济学直接相关；专家级 bit allocation 是 MoE 推理成本下一档下降的关键。
- [**Quantized Reasoning Models Think They Need to Think Longer, but They Do Not**](https://arxiv.org/abs/2606.00206) — 量化后模型"自以为需要更长 CoT"的伪现象；CoT 预算控制是 2026H2 RL post-training 的新议题。
- [**WaveFilter: Wavelet-Guided KV Cache Filtering for long-context diffusion LLMs**](https://arxiv.org/abs/2606.00724) — 与 GLM-5.2 / Gemini 3.5 Flash 1M+ context 部署直接挂钩。
- [**BAGEN: Are LLM Agents Budget-Aware?**](https://arxiv.org/abs/2606.00198) — 与 Patronus AI / Sail Research 融资逻辑同步：agent **每次 task 的 token + tool-call 预算** 正成为独立的训练/评测维度。
- [**MemPro: Agentic Memory Systems as Evolvable Programs**](https://arxiv.org/abs/2606.00619) — agent memory 表达为可演化程序而非向量；和 Whoop "My Memory" + Oura Advisor 升级的个人 AI memory 范式呼应。
- [**Skill or Skip? Selective Skill Invocation via Dual-Granularity Preference Learning**](https://arxiv.org/abs/2606.00510) — agent 在何时调用 skill / 何时跳过的 preference learning，agent harness 选型新参考。
- [**Agentic Transformers Provably Learn to Search via RL**](https://arxiv.org/abs/2606.00183) — 给 search-as-skill 这一类范式提供 RL 可学性证明。
- [**Learning to Construct Practical Agentic Systems**](https://arxiv.org/abs/2606.00189) — agent 系统组合的工程性综述，6 月被引用频次快速攀升。

## 想法

1. **GPT-5.6 白名单 + Anthropic-Alibaba distillation 事件叠加，意味着 frontier AI 已从 "市场产品" 升级到 "出口管制对象"，但管制对象不是 *模型*、是 *端用户*** — 这是过去 30 年最大的一次合规范式迁移（上一次是 Wassenaar arrangement 把 strong crypto 列入 dual-use）。**值得追踪**：(a) 白宫审批名单的 *grant rate* 与行业分布（金融 / 生物 / 国防 / 学术）— 这会决定 frontier model 在企业 SaaS 端是否变成 "*限量许可证经济*" (b) **被白名单卡住的客户会不会转向 GLM-5.2 / Mistral / Llama 体系**，从而把"主权 AI"从地缘叙事变成 *实际现金流分流*。

2. **DeepMind 顶尖人才连续转入 Anthropic / OpenAI，等同于 AI 三极结构（OpenAI / Anthropic / 中国 frontier）的市场预期被 *人才市场* 自我确认** — 与 §1 的白名单逻辑相互独立但同向。**值得思考**：(a) Google 是否会把 DeepMind 与 Google Research 的边界重新合并、并把"路径依赖性最强的"Gemini 产品线再次组织化重组？(b) Jumper / Shazeer 的薪酬包结构（很可能是 RSU + carve-out）若被披露，会把 *frontier scientist labor market* 的 clearing price 公开化，类似 GS / 高盛 trading 大佬转私募时 carry 公开化的市场清算时刻。

3. **Apple M6 → M7 跳代 + iPhone/Xbox 涨价 + chip rout = "AI 通胀 + AI 利润 + AI 路线图重排"三力同时落在硬件端** — 这是 6 月最被低估的 *硬件叙事拐点*。**值得思考**：(a) M7 系列若在 NPU 比例上做大幅倾斜（如 NPU > GPU TFLOPS），等同于**苹果第一次承认 *端侧 AI inference 是硬件升级的主驱动力，而不是显示 / 影像 / 续航***。(b) 这条与 NVIDIA 45°C 液冷（数据中心层 BOM 重塑）+ IBM sub-1nm（晶圆节点重塑）在 6/25 同日落地，**说明 AI 硬件栈在 *端 / 网 / 云 / 节点* 四层同时重排** — 上一次出现这种四层同步重排是 2007 年 iPhone 的 ARM + capacitive + WiFi/3G + iOS 同步落地。

4. **wearable 临床化的"合规 wedge"已经形成：FDA Whoop closeout + Samsung × Alcedis 注册级 endpoint + Oura × Lilly 处方药直供 = wearable 三向打通 (regulatory / clinical / pharma commercial)** — 这是 wearable AI 第一次完整跑通的"非消费电子飞轮"。**值得思考**：(a) 如果 *FDA closeout 模式* 成为标准，**Apple Watch / Pixel Watch 一整条 "AFib / blood-oxygen / 长 COVID / 睡眠呼吸"** 功能可以在不申请 SaMD 的前提下 *进入临床决策辅助叙事* — Apple Health 的 mind share 与 SaMD 路径策略需要重新评估 (b) Northeastern 这种 health-data 研究型机构，**是否能把 Oura × LillyDirect 模型在 Boston / NEU 医学中心做 pilot** — 把"消费数据 → 临床路径"的接入摩擦在学术联盟里先打通，会是 H2 一个可以下手的 sandbox。
