## 想法

1. **"反 AI 也是 distribution"**：HN 头条+DDG 流量+AI psychosis 三条信号叠加 → "human-touch" / "humans-only-by-design" 的产品 positioning 在 2026 下半年可能形成真正的 wedge。可穿戴里 Oura/Whoop 的 LLM Advisor 反过来也是机会：如果做 *opt-out of AI summarization* 的 raw data + 真人 coaching tier，会不会有 niche？
2. **Coding agent 的下一步是"垂直 vertical agents"**：Cognition ARR 13× 增长 + 自己出 SWE-1.6 模型 → frontier labs 之外，垂直领域（AEC、Health、Bio、Legal、Finance）的"私有 SWE-类"模型会重演这条曲线吗？AEC 这边 Hypar/Augmenta + LLM/agent 还是空白。
3. **AEC 上游的 "BIM-as-context" 机会**：Buildots 拿的是 *vision × BIM* 对账；下一层是 *agent × BIM*（plan-checking、code compliance、施工排程的多 agent 编排）。Autodesk Forma 没有完全占住这块，Higharc 和 Hypar 也只是局部。我手上有的语料可以构建一个简单的 BIM model context server（MCP）原型。
4. **Wearables 的真竞争从"采集精度"变成"长程因果叙述"**：Whoop Coach / Oura Advisor 都在做 narrative，但还是 single-modal。把 Whoop 心率 + 睡眠 + CGM patch + 主观日记同时喂给一个长 context 模型，输出 "为什么本周状态差"——这种 multi-source health agent 是研究 + 产品都没人做透的 niche。
