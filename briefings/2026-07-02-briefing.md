## 想法

1. **Meta Compute 是 *AI infra 二次分层* 的转折点** —— 从 "5 家 hyperscaler + 一堆 neocloud" 变成 "6 家 hyperscaler + neocloud 洗牌"。**深挖**：*CoreWeave / Nebius / Lambda 的 revenue mix 中 hyperscaler 反卖 (reseller) 占比*。若 Meta Compute 6-12 个月内做出 *inference API + 原始 compute* 双 SKU，则 **neocloud 中层公司 (< $10B valuation) 会在 2027 出现整合潮**。**副线**：Meta 有 Ohio "曼哈顿大小" 数据中心 → 直接采购 §5 Build 的 due-diligence 平台不是不可能，*hyperscaler 采购 AEC AI toolchain* 是 H2 最容易被忽略的整合方向。

2. **Copilot 收 open-weights 是 *IDE model routing* 从工程 stack 下沉到消费 stack 的分水岭**。**观察**：微软是否把 *auto model-selection* API 化 → 让 Cursor / Windsurf / Cline / Aider 变成 *前端 skin*，*底层 model routing 由微软官方产品化*。**如果发生**，*consumer developer 层的 API 定价* 会被 microsoft-managed subscription 完全吸收 —— OpenAI / Anthropic / Google 的 API 收入的 *IDE 直接终端占比* 会显著下降；**这是昨天 §笔记 Claude Code steganography 事件的 second-order 结局线**（*信任层危机 → 平台层收编*）。**副线**：中国开源 (ZCode + GLM / Kimi) 是否会推出 *自主 model routing 层*，避免被 Copilot 收编。

3. **AEC AI 的 *deliverable-selling 商业模式（Build）* 是重要 wedge**。相比 Higharc（SaaS / 供应链 API）+ OpenSpace（jobsite monitoring SaaS）+ Buildots（SaaS + benchmark data pool），Build 卖 *完成的 due-diligence 交付物*（+ 人 QA）—— **本质是 *AI-native services firm* 而非 AI-native software firm**。**观察**：McKinsey / BCG / Bain 是否会 *孵化 / 收购* 这类 *AI-augmented services micro-firm*，抢占 *AI × 咨询* market share。**副线**：如果 Build 6-12 个月内客户扩展到 hyperscaler 数据中心选址（Meta / AWS / Google / Microsoft），估值会跳到 $150-300M 区间。

4. **wearable 从消费 → 医疗 SKU 分层完成第一阶段**（Whoop 5.0 vs. MG，Oura Ring 5 全功能下推）。**观察点**：*FDA blood pressure pathway* 首个通过是 H2 最大单点催化；*Aetna / Optum / UnitedHealth 首个 rebate 公告* 是 wearable 商业模式二阶段起爆点。**副线**：**Apple 若无 AI Health Coach 落地（延期已确认），Apple Watch 在 medical-grade wearable 竞赛中会首次落后 Whoop / Oura**。
